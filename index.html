路愈者 RobotHealer

进行中In Progress
道路病害智能检测系统 · 无人机巡检 + 深度学习 Intelligent road-distress detection · drone inspection + deep learning

基于深度学习的道路病害（裂缝、坑洞、网裂等）检测系统，结合无人机巡检与轻量化边缘部署。已入围「挑战杯」，算法与系统集成均已部分完成，目前正处于装备开发阶段。 A deep-learning system for detecting road distress (cracks, potholes, alligator cracking) combining drone inspection with lightweight edge deployment. A "Challenge Cup" finalist; algorithm and system integration are partially done, and the project is currently in equipment development.
