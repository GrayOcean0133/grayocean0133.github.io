# AI-Link 智能装备社团 · 综合介绍材料（修订版）

> **AI-LINK GROUP** ｜ Slogan：**Think · Build · Connect**  
> 隶属于温州商学院信息工程学院 ｜ 社团展示网站：<https://grayocean0133.github.io/about.html>

AI-Link 智能装备社团聚焦“**智能装备 + 人工智能**”方向，由温州商学院信息工程学院两位博士教师共同担任指导老师。社团依托导师团队在计算机视觉、生成式 AI、智能交通、深度学习等方向的研究积累，组织成员开展算法研发、硬件集成、智能装备原型设计与学科竞赛实践。目前，社团已孵化出以“**路愈者 RobotHealer 道路病害检测系统**”为代表的产学研工程项目，并正推进试点应用与产业化探索。

## 四、社团代表性工程项目：路愈者 RobotHealer

社团目前已孵化出“**路愈者 RobotHealer 道路病害检测系统**”。该系统面向公路养护场景，是一套**多源数据一体化智能巡检系统**，融合视觉、激光雷达与无人机等多种感知方式，能够通过车载轻量化设备实时识别裂缝、坑槽、车辙等十余类道路病害，并自动输出标准化养护报告。

### 核心亮点

- 已获得 **第十五届“挑战杯”中国大学生创业计划竞赛**相关入围资格；
- 已在**江西九江长江大桥、江苏仪征省道、贵州白云区市政道路、浙江苍南县公路**等场景开展试点；
- 已与**九江长江公路大桥有限公司**、**苍南县交通局**等单位建立合作；
- 算法部分获得指导老师团队（张汉成博士、胡圆圆博士）的技术指导与支持，已申请 1 项软件著作权；
- 项目同步注册商业化主体**温州途垣科技有限公司**，迈出产学研转化第一步。

## 六、社团装备与硬件资源

社团搭建了“**AI 算力 + 空中感知 + 硬件原型**”三位一体的实验装备体系，具备从**模型训练**到**整机调试**的全栈自研能力，是孵化“路愈者”等工程级项目的重要基础。

### 6.1 AI 算力平台

#### 主力深度学习训练服务器（主机名：rs630）

| 项目         | 配置                                                                       |
| ------------ | -------------------------------------------------------------------------- |
| GPU          | **4 × NVIDIA RTX A6000**                                                   |
| 单卡显存     | 48 GB                                                                      |
| 合计显存     | **192 GB VRAM**                                                            |
| 驱动版本     | NVIDIA 570.211.01                                                          |
| CUDA 版本    | 12.8                                                                       |
| 主要用途     | 大规模深度学习模型训练、生成式 AI 微调、点云算法离线推理、多源数据融合训练 |

> **RTX A6000** 是 NVIDIA 面向专业工作站的高端 GPU。4 卡并行配置在同类高校学生社团中较为稀缺，可支撑大规模视觉模型训练、扩散模型训练、多源数据融合实验，以及在参数高效微调或量化策略下进行 70B 级大模型相关实验。

| 项目     | 配置                                                |
| -------- | --------------------------------------------------- |
| GPU      | NVIDIA RTX 3080                                     |
| 主要用途 | 日常算法验证、轻量化模型部署测试、成员个人 / 小组实验 |

### 6.2 空中感知装备

- **DJI Avata 360 无人机 × 1** —— FPV 飞行与 360° 全景拍摄能力结合的无人机平台；
- **应用场景**：桥梁底部、隧道、复杂建筑结构等狭窄空间的低空巡检与全景数据采集，并可配合车载平台形成“**空中 + 地面**”双视角感知能力。

### 6.3 电路与硬件原型实验设备

- 配备 **PCB（电路板）研发与调试设备**，包括示波器、焊接台等硬件实验工具；
- 支持社团自研嵌入式硬件、传感器模组与智能装备原型的**快速迭代**。

| 维度     | 优势                                                                        |

| 感知     | 空中（无人机）+ 地面（车载）双视角，覆盖多类巡检场景                         |

| 综合     | 算力、感知与硬件原型能力结合，支撑社团持续孵化工程级智能装备项目              |
